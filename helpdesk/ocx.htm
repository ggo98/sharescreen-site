HelpDesk - Installation des OCX

Introduction

HelpDesk nécessite un OCX. Celui ci doit être installé une fois.
Actuellement, vous devez installer le certificat DataSet HelpDesk OCX CA afin de pouvoir installer ces OCX.
Voici les différents écrans et étapes afin d'installer le certificat et le(s) OCX requis

Etapes

Internet Explorer signale qu'un activeX est nécessaire


(Cliquer sur Fermer)

Cliquer sur la barre jaune


ou

Cliquer "Exécuter le contrôle ActiveX"


La fenêtre suivante apparait


Cliquer sur "Editeur inconnu"

La fenêtre suivante apparait


Cliquer sur "Afficher le certificat"

La fenêtre suivante apparait


Cliquer sur "Installer le certificat"

La fenêtre suivante apparait


Cliquer sur "Suivant"

La fenêtre suivante apparait


Sélectionner l'option "Placer tous les certificats dans le magasin suivant" puis cliquer sur "Parcourir"

La fenêtre suivante apparait


Sélectionner "Autorités de certification racines de confiance" puis cliquer sur "OK"

La fenêtre suivante apparait


Cliquer sur "Suivant"

La fenêtre suivante apparait


Cliquer sur "Terminer"

La fenêtre suivante apparait


Cliquer sur "Oui"

La fenêtre suivante apparait


Cliquer sur "OK"

De retour dans Internet Explorer => cliquer sur le bouton "Actualiser"


La fenêtre suivante apparait


(Cliquer sur Fermer)

Cliquer sur la barre jaune


Choisir "Installer le contrôle ActiveX


La fenêtre suivante apparait


Cliquer sur "Installer"

Si vous avez installé la partie "Utilisateur de HelpDesk", La fenêtre suivante apparait


Cliquer sur "Demander du support"

La fenêtre suivante apparait


Saisir le nom (ou le texte) donné par la personne qui va fournir le support, puis cliquer sur "OK"
