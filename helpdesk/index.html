HelpDesk (Remote Control) pour Windows

Introduction

HelpDesk est un outil qui permet de voir et prendre le controle d'une machine Windows via Internet depuis une autre machine Windows, (à l'initiative de l'utilisateur qui souhaite être assisté).
L'outil est composé d'un Module Utilisateur, destiné à la personne qui demande l'aide, et d'un Module Maitre, destiné à la personne qui va assister l'Utilisateur.

Prérequis

  • Windows 2000/XP/2003/VISTA/WIN7/8/10/2012 (fonctionne, mais n'est plus supporté sous Win95,98,ME et Windows NT4)
  • Connection TCP/IP

Installation

Il suffit de décompresser chacun des fichiers ZIP dans un répertoire de votre choix.
A NOTER: sous Windows Vista, le module Utilisateur nécessite de privilèges Administrateur lors de la PREMIERE exécution, afin de s'auto-configurer.; entre autres pour se recopier dans le répertoire  des Programmes. Ceci est nécessaire à cause des nouvelles protections mises en oeuvre dans Windows Vista

Adware.Win32.Remote Control (DataSet)

Certains sites web, dont les auteurs n'ont apparemment pas pris la peine d'étudier correctement le logiciel,  se permettent de décrire cet outil comme étant malveillant.
Bien sur, tout outil permettant à deux ordinateurs de communiquer présente potentiellement un risque.
En ce qui concerne HelpDesk, il faut savoir que le produit, s'il est installé vonlontairement par l'utilisateur, est innocuite.

HelpDesk n'est en aucun cas prévu pour:
  • Voler vos informations,
  • Faire apparaitre des publicités intempestives,
  • Abimer ou ralentir l'ordinateur, etc...
