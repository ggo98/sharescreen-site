Utilisation de HelpDesk (coté Utilisateur)

Premiere étape: téléchargement et copie des fichiers

Introduction

Une fois téléchargé, l'intégralité du module utilisateur doit être décompressé dans un répertoire (par exemple C:\helpdesk, ou dans un dossier sur le bureau).
Ensuite, il sufft de lancer le programme helpdesk.exe depuis ce répertoire.
Sous Windows VISTA, une étape d'autoconfiguration est nécessaire, et se déclenchera automatiquement lors du premier démarrage de HelpDesk.

Après le téléchargement



Appuyez sur le bouton Ouvrir pour ouvrir le fichier zip téléchargé.

Fenêtre d'avertissement

Windows Vista affichera probablement la fenêtre d'avertissement suivante:

Cliquez sur le bouton Autoriser.

Copie du répertoire helpdesk - étape 1

Sélectionnez le répertoire Helpdesk, puis cliquez droit sur ce répertoire et cliquez 'Copier'

Copie du répertoire helpdesk - étape 2

Sélectionnez le répertoire Disque local (C:), puis cliquez droit sur ce disque et cliquez 'Coller'

Ouverture de l'arborescence du disque C

Cliquez sur la flèche () située à coté de Disque local (C:)

Exécution de Helpdesk.exe

Sélectionnez le répertoire helpdesk dans l'arborescence à gauche, puis double-cliquez le programme Helpdesk.exe afin de le démarrer.

Fenêtre de sécurité (Windows XP SP2 et VISTA)

Au premier démarrage, Windows XP SP2 et VISTA afficheront probablement une fenêtre de sécurité de ce type:
 
Cliquez sur Exécuter pour confirmer au système que vous souhaitez démarrer Helpdesk.exe
Dans le cas ou votre système est Windows VISTA, vous passerez par les étapes suivantes lors du premier démarrage uniquement.

Premier démarrage (avec Windows VISTA)

Si vous utilisez un système antérieur à Windows VISTA (XP, 2000, 98), vous pouvez  ignorer et passer cette partie.
Sous Windows VISTA ou supérieur, le programme doit s'autoconfigurer, car de nouveaux outils sécurités sont  présents dans ce système.
Voici donc ce qui va se passer au premier démarrage.
(Note: cette documentation assume que les paramètres de sécurité par défaut ont été conservés, ce qui devrait être le cas le plus souvent)

Copie de fichiers dans "Programmes"

L'application doit s'installer dans le répertoire "Programmes" (souvent C:\Program Files). La fenêtre suivante va donc apparaitre:
Cliquez sur Oui pour confirmer au système que vous souhaitez copier les fichiers de l'application dans le répertoire spécifié.
Normalement une fenêtre de "Copie de fichiers" doit apparaitre. Si celle-ci n'est pas visible, c'est normalement parce qu'elle est en arrière plan.
Dans ce cas, cliquez sur la fenêtre dont le titre est "Helpdesk" dans la barre des taches (en bas de l'écran):

Fenêtres de copies de fichiers et de création de répertoires

Des fenêtres de copies, remplacements, créations de fichiers et répertoires vont apparaitre. Confirmez et acceptez toujours les opérations proposées:
 
(Ici choisissez Copier et remplacer)
 
(Ici choisissez Oui)
 
(Ici choisissez Continuer)
 

Confirmation demandée par l'UAC (User Access Control de Windows VISTA) 

Si vous êtes connecté avec un profil Administrateur

la fenêtre suivante devrait apparaitre:
 

Choisissez Continuer.

Si vous n'êtes pas connecté avec un profil Administrateur

la fenêtre suivante devrait apparaitre:
 
Choisissez l'un des utilisateurs de type Administrateur présenté dans la liste, saisissez le mot de passe, et cliquez sur OK.

Encore quelques confirmations demandées par Windows VISTA...


 
Acceptez différentes opérations proposées.

Dernières étapes

Une fois la copie des fichiers effectués, l'application doit installer un certificat afin que Windows VISTA puisse exécuter HelpDesk correctement.
La fenêtre suivante devrait apparaitre:
 
Cliquez sur OK.
 
Répondez Oui.

Si vous êtes connecté avec un profil Administrateur

la fenêtre suivante devrait apparaitre:
 
Choisissez Autoriser.

Si vous n'êtes pas connecté avec un profil Administrateur

la fenêtre suivante devrait apparaitre:
 
A nouveau choisissez l'un des utilisateurs de type Administrateur présenté dans la liste, saisissez le mot de passe, et cliquez sur OK.

Fin de configuration

La phase de configuration est désormais terminée !
 
Cliquez sur OK, puis redémarrez HelpDesk.exe
A NOTER:
Windows VISTA peut afficher la fenêtre suivante (une fois seulement):
 
Répondez que Ce programme fonctionne correctement. 

Fenêtre de connexion vers le PC de la personne qui va fournir l'assistance

HelpDesk affiche la fenêtre suivante afin de vous permettre de définir les paramètres de connexion au PC de la personne qui va pouvoir (temporairement) voir et controler votre ordinateur.
Le paramètre principal est Help desk machine Name / IP Address. C'est à la personne qui va vous assister de vous fournir la valeur de ce paramètre.
Il peut s'agir d'une adresse IP (comme ici: 192.168.0.208), d'un nom, ou de plusieurs noms/lettres/chiffres séparés par des points, le tout éventuellement complété par ":pppp", ou pppp sont des chiffres (en l'occurence un N° de port TCP/IP).
Vous ne devriez pas avoir à définir le paramètre Web Proxy; ce dernier peut devoir être défini dans le cadre d'une utilisation en entreprise.
 
Cliquer sur OK. La fenêtre de confirmation suivante apparait:
 

Cliquez sur Oui.

Etablissement de la connexion

Pendant la phase de connexion, la fenêtre suivante apparait:

 

Une fois la connexion établie, HelpDesk vous en informe:

 

La personne qui va vous assister peut normalement désormais voir votre écran, ainsi que prendre le contrôle de la souris et du clavier afin de vous expliquer une manipulation.
Dans le cas ou une un autre message est affiché, demandez à la personne qui doit vous assister ce qu'il faut faire...
Il peut s'agir d'un firewall ou d'un routeur qui bloque la connexion sur votre machine, ou sur la machine de la personne qui doit vous assister. (voir les messages d'erreur référencés)

Notez que HelpDesk (Remote Control Server) est visible dans la barre des taches (en bas à droite par défaut)


Messages d'erreur référencés

10022

 
Ce message signifie généralement la correspondance entre un nom de host (spécifié dans Help desk machine Name / IP Address) et son adresse IP n'a pas été trouvée.
Il peut également s'agir d'une erreur de saisie de ce paramètre.

10060

 
Ceci peut signifier plusieurs choses:
  • Le réseau Internet n'est pas disponible ("tombé")
  • Le nom saisi dans Help desk machine Name / IP Address ou le N° de port spécifié est incorrect
  • Un pare-feu (firewall) ou routeur empêche la connexion sur le port TCP 7429 (port par défaut si non précisé) ou sur le port spécifié; ceci du coté du client (le port n'est pas ouvert en "sortie") ou du serveur (le PC maitre n'est pas configuré de façon à accepter des demandes de support sur le port TCP 7429 ou autre)

10061

 
Ceci peut signifier plusieurs choses:
  • L'adresse IP ou le nom spécifié saisi dans Help desk machine Name / IP Address est correct, mais il n'y a pas de serveur pour répondre à la demande (possible erreur de saisie)
  • Toutes les possibilités de l'erreur 10060


10004

 
Ce message apparait normalement si vous appuyez sur le bouton Cancel pendant la phase de connexion.

Personne du support non disponible

 
Ce message apparait normalement si la personne qui a reçu votre demande de support a répondu non la demande.
