smallRouter pour Windows

Introduction

smallRouter est un utilitaire de routage. Il permet de rediriger un port TCP ou UDP vers un autre, ou un port TCP ou UDP vers une autre machine, ou les deux. (par ex: peut 'router' les connexion TCP de [Machine1:8888] vers [Machine2:80]).

Prérequis

  • Windows 2000/XP/2003/VISTA (fonctionne, mais n'est plus supporté sous Win95,98,ME et Windows NT4)
  • Connection TCP/IP
