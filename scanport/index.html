Scanport pour Windows

Introduction

Scanport est un utilitaire de scan de port TCP.

Prérequis

  • Windows 2000/XP/2003/VISTA (fonctionne, mais n'est plus supporté sous Win95,98,ME et Windows NT4)
  • Connection TCP/IP
